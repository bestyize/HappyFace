# 表情参数与事件协议草案 v0.1

本草案优先保证三款横屏盒子（800×480、400×320、320×240）可复用。`ExpressionIntent` 在任意屏幕上使用归一化坐标，绘制层根据当前画布计算光学中心和安全区。手机竖屏另作布局配置。

## 基础形态

`CALM`、`CURIOUS`、`HAPPY`、`SHY`、`THINKING`、`SLEEPY` 是初始形态标签，不对应固定图片。强度、视线和持续时间与形态共同决定目标参数；后续可扩展眼形、嘴形、脸颊、色彩、注意力与动作强度。

## 高层指令（拟定的云端协议，尚未接入 API）

```json
{
  "mood": "CURIOUS",
  "intensity": 0.7,
  "gazeX": -0.4,
  "gazeY": 0.1,
  "holdMs": 2200
}
```

- `intensity` 范围为 0–1；`gazeX/gazeY` 范围为 -1–1；超范围输入在设备本地裁剪。
- 未知形态与无效载荷应被拒绝，回退到安全的 `CALM` 状态。
- 大模型输出一个高层意图，本地引擎负责每帧插值、眨眼、呼吸和动作叠加。
- 触碰、悬停、系统状态和将来的语音输入都先转为本地事件；触碰无需联网。
- 优先级拟定：硬件安全/离线提示 > 用户实时触碰 > 对话表情 > 自主待机动作。实际时间线与打断策略在 P1 确认。

## P0 演示实现

当前代码只实现形态、强度与视线；`holdMs`、事件队列和云端数据校验尚未实现。测试验证参数裁剪、同种子微动作可复现，以及切换时从当前状态连续移动。
